# Day 18 RAG Parameter Test

测试问题：

How does the azimuth-controllable generative adversarial network control the azimuth angle of generated SAR target images?

索引参数：

- Chunk Size: 600
- Chunk Overlap: 100
- Embedding Model: BAAI/bge-m3


## Top-k

### Top-k = 1

检索完整性：

较低。只检索到少量与问题相关的内容，能够找到“双输入并行 SAR 图像输入块”和生成中间方位角图像等信息，但没有检索到方位角预测器等更具体的控制机制。

回答完整性：

较低。回答能够说明网络可以生成位于两个输入方位角之间的 SAR 图像，但无法解释网络具体如何对方位角进行约束和优化。

无关信息：

很少。由于只检索 1 个文档块，回答比较集中，基本没有无关信息。

引用情况：

引用数量较少，仅使用 [1]。引用与回答内容基本对应，但支撑信息有限。


### Top-k = 3

检索完整性：

中等。相比 Top-k = 1，获得了更多关于生成器、判别器、预测器以及 ATGAN 的相关信息，对网络结构的描述更加完整。

回答完整性：

中等。能够说明双输入 SAR 图像及特征融合的作用，但仍然没有找到足够的信息解释方位角预测器、损失函数等具体控制机制，因此回答比较保守。

无关信息：

较少。加入了 ATGAN 等相关研究信息，这些内容与问题有关，但并不是回答当前问题所必需的核心内容。

引用情况：

使用 [1][2][3] 等多个引用，引用覆盖范围比 Top-k = 1 更广。


### Top-k = 5

检索完整性：

较高。能够检索到两个不同方位角 SAR 图像作为输入、双输入并行 SAR 图像输入块、目标特征提取与融合，以及生成图像方位角由输入图像方位角约束等关键信息。

回答完整性：

较高。已经能够较清楚地回答网络控制方位角的基本机制，即通过两个已知方位角的 SAR 图像作为条件输入，提取并融合目标特征，从而生成位于两个输入方位角之间的 SAR 图像。

无关信息：

较少。检索内容基本围绕问题展开，没有出现明显与问题无关的信息，信息量和相关性之间比较平衡。

引用情况：

主要使用 [1][3][4]，多个检索结果能够相互补充和验证回答内容，引用比较充分。


### Top-k = 10

检索完整性：

很高。检索到了生成器、判别器、方位角预测器、双输入结构、相似性判别器以及方位角预测器损失函数等更加详细的信息。

回答完整性：

很高。能够进一步说明方位角预测器用于衡量生成图像方位角与目标方位角之间的差异，并利用该误差信息优化方位角控制，因此对网络内部控制机制的解释最完整。

无关信息：

有所增加。虽然检索到的大部分信息仍然与问题相关，但已经出现了一些相对次要的细节，例如使用均方误差代替对数误差等。对于回答“如何控制方位角”这一问题而言，这些信息不是必需的。

引用情况：

引用最丰富，使用 [1][3][4][7][9] 等多个来源，对不同结论提供了较充分的支撑。


## Temperature

### Temperature = 0

稳定性：

高。回答比较确定、保守，基本只使用检索到的明确事实，不容易产生额外推断。

回答长度：

较短。主要直接说明两个输入 SAR 图像方位角与生成图像中间方位角之间的关系，没有进行过多扩展。

引用：

使用 [1][4]，引用数量较少，但能够支持主要结论。


### Temperature = 0.2

稳定性：

较高。回答仍然比较确定，同时能够适度组织和整合多个检索片段的信息。

回答长度：

中等。相比 Temperature = 0，增加了双输入并行结构、特征提取与融合等解释，信息更加完整，但没有明显冗余。

引用：

主要使用 [1][3][4]，引用较充分，能够支持回答中的主要观点。


### Temperature = 0.7

稳定性：

中等。当前实验中回答仍然基本忠于检索内容，没有出现明显幻觉，但语言组织和扩展程度比低 Temperature 更自由。

回答长度：

中等偏长。相比 Temperature = 0，加入了更多对网络结构和作用机制的解释，但与 Temperature = 0.2 的核心结论基本一致。

引用：

主要使用 [1][3][4]，引用情况良好，与回答中的主要结论基本对应。


## 暂定结论

当前默认参数：

Top-k = 5

Temperature = 0.2

原因：

Top-k = 1 时检索信息明显不足，难以回答网络具体如何控制方位角；

Top-k = 3 能够获得更多相关信息，但仍然缺少部分关键机制；

Top-k = 5 已经能够覆盖双输入 SAR 图像、特征提取与融合以及输入方位角约束等主要信息，在检索完整性和无关信息数量之间取得了较好的平衡；

Top-k = 10 虽然能够获得最完整的信息，并进一步检索到方位角预测器和损失函数等细节，但同时增加了次要信息，检索和生成成本也会更高。

Temperature = 0 的回答比较稳定，但内容相对简短和保守；

Temperature = 0.7 能够生成较丰富的描述，但生成自由度更高，对于要求严格依据论文知识库回答的 RAG 系统而言，潜在幻觉风险也相对更高；

Temperature = 0.2 在稳定性、回答完整性和表达能力之间取得了较好的平衡。

因此，目前暂时选择：

Top-k = 5

Temperature = 0.2

作为系统默认参数。

注意：

当前只是针对单个测试问题进行的小规模人工实验，样本数量有限，因此只能作为参数选择的初步依据，不应视为最终评测结论。

后续应增加不同类型的问题，例如事实型问题、机制解释型问题、论文比较型问题和跨论文综合型问题，并从检索相关性、回答完整性、引用正确性、幻觉率和响应成本等多个维度进行系统评测后，再确定最终默认参数。
